# README 图片

| 文件 | 来源与处理 |
|---|---|
| `cover.svg` | 为本项目绘制的标题图，沿用应用的箭头标志和绿色主题；不表示额外功能 |
| `routes.webp` | 维护者提供的实际线上杭州旅行截图；保留原始分辨率，无损 WebP，移除图片元数据，保留高德地图署名 |
| `home.webp` | 维护者提供的实际线上首页截图；保留原始分辨率，无损 WebP，移除元数据 |
| `places.webp` | 开发过程中保存的真实地点搜索界面局部；裁掉含人物的第三张卡片 |

这些图片用于展示应用现有界面，没有把概念图或生成图片作为功能截图。截图中的地图、地点照片、商标与标识属于各自权利人，不随源码的 MIT 许可证重新授权。高德地图的署名应保留。不要从截图提取照片作为素材库分发。

更新截图前检查邮箱、私人行程、登录令牌、浏览器标签、通知和定位信息。使用示例数据，并清除 EXIF 等元数据。

界面截图不缩小像素尺寸、不使用有损压缩；局部截图也使用无损 WebP。README 中受栏宽限制的全屏截图可点击查看原图。
